# LullyRest — Project Index

DTC Shopify store for the LullyRest Orthopedic Cervical Pillow. Start here to orient; see `CLAUDE.md` for the standing operating rules Claude Code follows in this project.

## Structure

- `research/` — synthesized target-audience, offer, belief-chain, and voice-of-customer reference docs, plus the original source documents in `research/source-docs/`.
- `brand/BRAND_GUIDE.md` — positioning, big idea, tone/voice, naming status. `brand/assets/` — logo/product/lifestyle/social files (empty until produced).
- `marketing/` — campaign-facing deliverables. `PRESELL_LISTICLE.md` (the page that was built), `PRESELL_ADVERTORIAL.md` (long-form fallback), `PDP_COPY.md`.
- `theme/` — custom Liquid sections, blocks, snippets, CSS and JSON templates for the draft Shopify theme. Our files only; the Elixir base theme is vendor code and is not tracked. See `theme/README.md`.
- `CLAUDE.md` — standing safety rules and store access info for this project.
- `PROGRESS.md` — audit log of every store mutation and meaningful project change.
- `SHOPIFY_BOOTSTRAP.md` — the reusable runbook this project was bootstrapped from.
