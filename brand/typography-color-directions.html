Four directions for LullyRest's visual identity

Built for the audience in research/AUDIENCE.md: skeptical, analytical, high-earning knowledge workers who've already been failed by "plush comfort" bedding marketing. Each direction pairs a color system with a type system and shows both applied to real brand copy — headline, trust bullets, and the "kinked cable" mechanism motif from brand/BRAND_GUIDE.md.

Naming and domain are still unresolved per the brand guide — none of this locks in a public-facing asset. Pick a direction (or mix an ink/paper pairing from one with the accent from another), then bring it back here to draft the full guide.

Authority bias

Navy ink + an editorial serif reads institutional — closer to a journal than a mattress-store flyer. Matters more here than "friendly," since friendly is what already failed this buyer.

Processing fluency

A spare grid with one measured accent reads as more truthful than a saturated, decorative page. Skeptical buyers infer credibility from restraint, not enthusiasm.

Von Restorff effect

Signal teal is used nowhere except mechanism content, so the C1–C3 diagram is the one thing on the page the eye can't skip past.

Fluency as trust

This audience "dismisses generic plush comfort claims" per the audience research. A page with almost no ornamentation reads like a mechanism they can verify, not a mood they're meant to buy into.

Contrast effect

After a category of soft, centered, pastel bedding pages, a page built like a spec sheet is itself the differentiator — no claim required.

Choice architecture

One accent color, one job — proof numbers. Removes the ambiguity a paradox-of-choice-prone skimmer would otherwise stall on.

Color-emotion association

Sage reads as clinical-calm — exam room, not spa — which fits "clinical, not clinical-cold" without sliding into soft DTC-bedding pastel.

Pattern interrupt

A dark, slab-serif page breaks the visual pattern of every competitor's bright, airy bedding site — the mass bedding industry the brand guide names as the actual antagonist.

Von Restorff effect

Clay is isolated to the kink diagram only, so the one visual "aha" — nerve compression — is the one thing that pops off an otherwise quiet page.

Choosing between them

All four use the same mechanism motif and the same trial/VOC facts — only the emotional entry point changes. None of them are mutually exclusive: the ink/paper pairing from one can run with the accent from another.
