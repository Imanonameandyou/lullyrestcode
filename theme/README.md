# Theme

Custom LullyRest theme code. **Only our own files live here** — the base theme is vendor code and is not tracked in this repo.

## Where this deploys

| | |
|---|---|
| Draft theme | `LullyRest — Presell + PDP (draft)` — `gid://shopify/OnlineStoreTheme/162852077782` |
| Base | Duplicated from `elixir-1-6-1-pillow` (`162845229270`) on 2026-08-19 |
| Live theme | **Horizon** (`162844639446`) — never written to, per `CLAUDE.md` rule 2 |

## Files

- `assets/lullyrest.css` — scoped styles on the locked Direction C tokens. Everything is namespaced `.lr-` so it cannot leak into Elixir's components.
- `snippets/lullyrest-kink-diagram.liquid` — the recurring "kinked cable" mechanism diagram, inline SVG. Mirrors `brand/assets/kinked-cable-diagram.svg` but **drops that file's `prefers-color-scheme` block**: the storefront background is theme-controlled, so reacting to the visitor's OS theme would invert the strokes into invisibility on a light page.
- `snippets/lullyrest-zones.liquid` — the four-zone breakdown, shared by the block and section versions so the spec exists once.
- `blocks/lullyrest-mechanism.liquid`, `blocks/lullyrest-zones.liquid` — theme blocks for use *inside* Elixir's `listicle` and `cs-content` containers.
- `sections/lullyrest-*.liquid` — standalone section versions for the PDP.
- `sections/lullyrest-proof-placeholder.liquid` — reserved social-proof slots, deliberately empty and labelled.
- `templates/page.presell.json`, `templates/product.lullyrest.json` — generated by `build_templates.py`.

## Vendor patches (not tracked — reapply after any re-pull)

`build_templates.py` patches two Elixir files so our blocks are selectable inside them. Both edits only append to the schema `blocks` array:

- `sections/listicle.liquid` → accepts `lullyrest-mechanism`, `lullyrest-zones`
- `blocks/cs-content.liquid` → accepts `lullyrest-mechanism`, `lullyrest-zones`

**If you re-pull the theme, these patches are lost.** Re-run `build_templates.py` to reapply.

## Deploying

```bash
shopify theme pull  --store eug1kz-w0.myshopify.com --theme 162852077782 --path /tmp/draft-theme
python3 build_templates.py          # copies our files in, patches vendor schemas, regenerates templates
shopify theme push  --store eug1kz-w0.myshopify.com --theme 162852077782 --path /tmp/draft-theme --nodelete \
  --only "templates/page.presell.json" --only "templates/product.lullyrest.json" \
  --only "sections/lullyrest-*" --only "blocks/lullyrest-*" --only "snippets/lullyrest-*" \
  --only "assets/lullyrest*" --only "sections/listicle.liquid" --only "blocks/cs-content.liquid"
```

Push blocks **before** templates that reference them — Shopify rejects a template whose block types don't yet exist on the theme.

## Gotchas hit while building this

- Theme block/preset `name` is capped at **25 characters**. "LullyRest mechanism diagram" (27) was rejected.
- `listicle-item.image` and `cs-image.image` are `image_picker` — they resolve **Shopify Files**, not theme assets. The four product renders are uploaded to Files as `lullyrest-{hero,side,top,cross}.png` and referenced as `shopify://shop_images/…`. The same PNGs also exist in `assets/` for our own sections, which use `asset_url` instead.
- `themeDuplicate` returns `newTheme`, not `theme`.
- `shopify theme pull --path` requires the directory to already exist.
